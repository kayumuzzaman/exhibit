Exhibit records in DevTools

Exhibit is a DevTools panel, so it opens inside DevTools rather than in this menu.

On Next.js apps it decodes Server Actions, RSC navigations, and Flight payloads. On any site it explains the requests a page sent and redacts known credentials before showing them.

  1. Open a normal http:// or https:// page.
  2. Open DevTools with F12, Ctrl+Shift+I, or ⌥+⌘+I on macOS.
  3. Select the Exhibit tab, then press Record.

If DevTools is already open, this menu can jump straight to the panel.
