Payloadra records in DevTools

Payloadra is a DevTools panel, so it opens inside DevTools rather than in this menu.

  1. Open a normal http:// or https:// page.
  2. Open DevTools with F12, Ctrl+Shift+I, or ⌥+⌘+I on macOS.
  3. Select the Payloadra tab, then press Record.

If DevTools is already open, this menu can jump straight to the panel.
